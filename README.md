# prakhar-portfolio

Portfolio website for Prakhar Patni — production GenAI, automation and editorial commerce.

## Deploy
- Upload `index.html` to repo root.
- Settings → Pages → Deploy from branch → main / root.
- Live at https://uniqprakhar.github.io/prakhar-portfolio/ (or custom domain).

## Edit contact links
Search in index.html for `hello@example.com`, `linkedin.com`, `wa.me/91` and replace.
